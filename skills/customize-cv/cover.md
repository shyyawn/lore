# Cover letter

Default is **no**. A short note when asked, or the portal requires
it. Do not write one as a drive-by. Do not recopy the CV.

Sources: 2026 recruiter skim (150–250 words, three short
paragraphs). Job CV: SKILL.md. Tone: [tone.md](tone.md). Facts:
[career.md](career.md).

## Defaults

| Job | Default | Honor instead when |
| --- | --- | --- |
| Write | **no** | user asked; portal / posting requires it |
| Length | 150–250 words, three short paragraphs | — |
| Open | Their problem + one SOURCE proof | "I am writing to express my interest" |
| Why-them | One true line from SOURCE, or omit | Invented blog; "passionate about your mission" |
| File | `<folder>/out/<company>-<role>-cover.md` | user named a path |

## Earn a letter

Copy this checklist. Tick **yes** on at least one, or **stop**.

```
Earn a cover letter:
- [ ] Portal or posting requires it
- [ ] User asked
- [ ] Direct to a hiring manager, or a small company, and SOURCE has a real why-them
```

If every line is **no**, do not write one. A generic letter hurts
more than none.

## Default shapes

```
# Cover: <company> <role>

<Name>
City · email · phone

<Hiring manager or Hiring team>,

<Their problem from the JD. One SOURCE proof that maps.>

<Two matches, each a fact. Not the whole CV.>

<One true why-them from SOURCE, or omit. Close: available. Write to email.>
```

No "I am writing to apply". No adjective about the self
(passionate, dedicated, results-driven).

## Write the letter

After the job CV for this ask. Same SOURCE. Same lane.

```
Cover letter:
- [ ] Earned (else stop)
- [ ] Career source inventoried
- [ ] Three short paragraphs, 150–250 words
- [ ] Opens on their problem + one proof
- [ ] Does not recopy the CV
- [ ] Why-them is true or omitted
- [ ] Tone ticks ([tone.md](tone.md))
- [ ] Draft written to <folder>/out/<slug>-cover.md
```

1. Take two JD must-haves the source can defend. One proof each.
2. Open on the company's problem, not on "I".
3. Close in one line. Write to email. Do not plead.

## When it breaks

| Symptom | Usually means |
| --- | --- |
| I am writing to express my interest | Model opener |
| Recopied the CV | Did not pick two facts |
| Passionate about your mission | Invented why-them |
| Longer than a skim | Did not earn brevity |
| Reads like ChatGPT | Did not follow [tone.md](tone.md) |

## LLM traps — never generate these

- I am writing to apply / express my interest
- Passionate about your mission to …
- A generic letter reused for every company
- The whole CV in prose
- Always-on letter when Earn is no

## Do not

- Write a letter because this file exists.
- Invent a blog post or product love the source does not have.
- Ship a letter that fails [tone.md](tone.md).
