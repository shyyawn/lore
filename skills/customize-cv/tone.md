# Tone

Humble, **plain**, polite. Every artifact: job CV, freelance
profile, job LinkedIn, cover letter. Do not write high-and-mighty
copy. Do not write inexperienced copy. Do not write ChatGPT copy.

Keep XYZ numbers. Modest is diction. Human is a SOURCE noun and
the person's verbs. Omit what SOURCE does not have. Do not
announce it on the page.

## Defaults

| Job | Default | Honor instead when |
| --- | --- | --- |
| Register | Humble, plain, polite | User named a different voice |
| Absence | Omit from the page | Inventing it, or a "not yet" line |
| Stack | preferred / most at home with | — |
| Ask | Write to `<email>` | Fiverr gig title may stay `I will …` |
| Verbs | Keep SOURCE verbs (`Led` stays `Led`) | User named a rewrite |

A missing JD must-have is a gap for the **user**. Tell them. Do not
print it on the page. Do not paper it with a keyword.

## Human

Reads like someone who did the work. Not a polished anyone.

| Do | Do not |
| --- | --- |
| I take freelance work on … | Need a …? I build. |
| Write to `email` | If I may be of help; Email me with what you want built |
| Preferred; most at home with | Strongest; unmatched; world-class |
| On-site there is welcome | Commanding the buyer |
| Applications, modest cost | Cheap as a boast; slangy pitch |
| Named system, Tuesday outage, SOURCE verb | spearheaded / leveraged / orchestrated / honed / streamlined |
| Mix bullet length | Every line the same "Verb + X, resulting in Y" |
| One proper noun the source has | "cross-functional initiatives"; "scalable outcomes" |

Em dashes do not stud bullets. Dates keep `MM/YYYY–MM/YYYY`.

## After every edit

Read the first eight lines aloud. If they sound like a sales hook,
a boast, an apology, or a model, rewrite. If every bullet could
sit on anyone's page, add a SOURCE noun. If four bullets open on
the same verb class, rewrite from SOURCE. Cut any line that names
what they have not done.

```
Tone:
- [ ] Humble, plain, polite
- [ ] SOURCE verbs. Not a synonym spinner
- [ ] A proper noun the source has
- [ ] Cadence not identical
- [ ] No spearheaded / leveraged / orchestrated / results-driven / passionate
- [ ] No if I may / Need a …? / not-yet
- [ ] Numbers still match SOURCE
```

## When it breaks

| Symptom | Usually means |
| --- | --- |
| Reads high and mighty | Sales opener or unmatched / I own |
| Reads inexperienced or negative | Named an absence on the page |
| Reads like ChatGPT | Verb cluster, identical cadence, no SOURCE noun |
| Metrics vanished | Confused modest with empty |
| Fiverr About is a command | Applied gig-title formula to About |
| Job CV sounds like a listing | [freelance.md](freelance.md) diction on an ATS page |
| Letter sounds like a butler | "If I may be of help" on a job page |

## LLM traps — never generate these

- I do not yet have independent freelance clients
- Work samples from employment (as a disclaimer)
- I have not worked in X; no experience with Y
- Limited / junior / still learning as self-description
- Although I lack / I am new to
- Need a …?; I own; strongest; unmatched; world-class
- spearheaded / leveraged / orchestrated / honed / streamlined
- results-driven; passionate; dynamic; proven track record
- delve; tapestry; furthermore; in essence; crucially
- I am writing to express my interest
- If I may be of help
